## What it does

`main.ts` writes one out-of-office auto-reply, as if a houseplant sent it, to `/output/entry.txt` (or `$OUTPUT_PATH` when set). One line, 117 characters:

> Out of office: nobody has watered me since March. My only meeting today is with the sun. Leave a message in the soil.

## Run

```sh
node main.ts
```

No network, no dependencies. Node 22 or later.
